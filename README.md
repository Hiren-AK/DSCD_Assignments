# Distributed Systems — Course Portfolio

This repository is a portfolio of distributed-systems course assignments demonstrating RPC (gRPC), message-passing (ZeroMQ, RabbitMQ), consensus (Raft), and MapReduce (K-means).

Contents
- 01-comm-messaging/ — gRPC, ZeroMQ, RabbitMQ examples
- 02-raftkv_leader_lease/ — RaftKV (Raft with leader lease)
- 03-mapreduce_kmeans/ — MapReduce K-means implementation

Quick start
1) Install Python requirements (examples use grpcio/grpcio-tools, pyzmq, pika):

```bash
pip install grpcio grpcio-tools pyzmq pika
```

2) See each project README for run instructions.
